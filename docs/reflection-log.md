## Phase 1 — 요구사항 확정 (CLAUDE.md)

> 재구축 전에 `README2.md`를 기반으로 `CLAUDE.md` 초안을 AI가 쓰고, 사용자가 읽고 고쳤다. Phase 0에서 AI가 임의로 채운 가정을 하나씩 사용자가 직접 정했다.

### P1-1. AI 초안을 그대로 쓰지 않고 본인 경험으로 고쳐 썼다

- **상황**: 과제는 "AI에게 초안을 시켜도 되지만 반드시 읽고 고쳐야 한다"고 했다. AI가 만든 초안의 "프로젝트 한 문장"은 AI가 가정한 불편(체험 만료를 놓쳐 의도치 않은 결제)이었다.
- **프롬프트 원문**: "기존 index.html의 내용을 싹 지우고, CLAUDE.md의 규칙에 따라 처음부터 다시 구축할 거야. 일단 README2.md 파일을 읽고 요구사항에 맞게 CLAUDE.md 초안을 작성해줘."
- **AI 출력/결과**: 한 문장을 `[확인 필요]`로 표시하고 "본인이 실제로 겪은 불편으로 고치기"라고 남겼다. 하드 제약, 작업 방식(한 번에 하나, 계획 먼저, 커밋, 검증), 성찰 기록 규칙을 담았다.
- **내 판단**: 사용자가 직접 한 문장과 "기존에는" 문장을 본인의 불편으로 다시 썼다. ("통장 잔고 관리가 안되는 상황에서 이번 달 남은 기간 동안 빠져나갈 구독료 총합과 각 서비스의 결제·만료일을 시각적으로 한눈에 확인", "다른 일정 알림들에 묻히는 문제") [이유를 더 쓰려면: 작성 필요]
- **대응 및 전/후 비교**: AI 초안은 "결제일·만료일 시각화"에 가까웠고, 사용자가 쓴 문장은 **"이번 달 남은 구독료 총합"**이라는 핵심 지표를 추가했다. 이후 요구사항(요약 카드, 월별 총액)이 이 문장에서 나왔다.
- **증거**: 커밋 `b814793`, `1a1726a`

- **내 판단**: 사용자가 월 환산 평균을 명시적으로 배제했다. [이유: 작성 필요]

### P1-4. 모호한 규칙 문구를 사용자가 지적했고, AI가 확인 후 다시 썼다
