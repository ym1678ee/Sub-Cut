### 사례 1. 요청하지 않은 기술 결정을 AI가 전부 채웠다

- **상황**: 턴 1에서 "앱 만들어 줘"만 요청했다. 스택, 저장 방식, 화면 구성을 지정하지 않았다.
- **프롬프트 원문**: "정기 구독 결제일과 무료 체험 만료일을 시각적으로 보여주는 앱 만들어 줘."
- **AI가 임의로 정한 것**:
  - 단일 `index.html` 파일, 빌드 도구 없음, 바닐라 JS
  - 저장은 브라우저 `localStorage`
  - 화면은 한 페이지에 폼, 목록, 월간 캘린더, 요약 카드를 모두 배치
  - UI 언어는 한국어 (요청에 언어 지정 없음)
  - 등록 항목은 이름, 종류(결제/체험), 날짜, 주기(매월/매년/매주), 금액
  - 요청에 없던 "예시 데이터 넣기"와 "전체 삭제" 버튼
- **결과**: 요구사항과 하드 제약(정적 웹, 백엔드 없음)에는 우연히 맞았다. 다만 AI가 이 가정들을 만들기 전에 묻지 않았고, 사용자가 알게 된 것은 결과물을 본 뒤였다.

- **대응 및 전/후 비교**: [작성 필요] (재구축 시 `CLAUDE.md`에 스택·저장 방식·화면 수를 명시함)

### 사례 2. 체험 진행 막대의 기준을 AI가 숨은 가정으로 정했다

- **상황**: 체험 만료일까지 얼마나 남았는지를 막대로 표시해야 했는데, 입력 항목에 체험 시작일이 없었다.
- **AI의 결정**: 체험 기간을 **30일**로 가정하고 `1 - 남은일수/30`으로 진행률을 계산했다. 7일짜리 체험이면 처음부터 막대가 상당히 차 있는 것처럼 보인다.
- **드러난 시점**: 구현과 함께 AI가 결과 보고에서 "30일 기준으로 계산해요"라고 밝혔다. 사용자가 묻기 전에 한계는 공개됐지만, 요구사항으로 정해진 값은 아니다.
- **내 판단**: [작성 필요]
- **대응 및 전/후 비교**: [작성 필요] (예: 시작일 입력 추가, 또는 막대 제거)
- **증거**: 커밋 `a377a52`, `index.html`의 진행률 계산 부분

### 사례 3. "월 예상 지출" 환산 규칙을 AI가 임의로 정했다

- **상황**: 요약 카드에 월 예상 지출을 보여주려면 연 결제와 주 결제를 월 금액으로 바꿔야 한다.
- **AI의 결정**: 연 결제는 ÷12, 주 결제는 ×52/12(약 4.33)로 환산했다. 체험 항목은 합계에서 제외했다. 체험이 끝나면 결제될 금액은 포함하지 않는다.
- **결과**: 예시 데이터 기준 41,900원으로, 직접 계산한 값과 일치함을 확인했다. 다만 "체험 종료 후 결제될 금액을 포함할지"는 사용자에게 묻지 않고 정했다.
- **내 판단**: [작성 필요]
- **증거**: 커밋 `a377a52`, 점검 스크린샷

### 사례 4. "동작한다"는 보고와 실제 검증의 간극

- **상황**: 턴 1 직후 AI가 앱을 완성했다고 보고했다. 이때 실제로 한 검증은 `node --check`(스크립트 문법 검사)뿐이었고, 브라우저에서 실행하지는 않았다. 보고에는 "문법 검사만 했고 브라우저에서 띄워 보지는 못했다"고 적었다.
- **이후**: 턴 4에서 점검을 위임하자 AI가 헤드리스 Chrome으로 31개 항목을 자동 테스트했고 전부 통과했다. 라이트/다크 스크린샷도 확인했다.
- **관찰**: 이번에는 검증 전 보고가 결과적으로 맞았다. 하지만 맞았다는 근거는 사후에 생긴 것이며, 턴 1 시점에는 "문법이 맞다" 이상의 증거가 없었다.
- **내 판단**: [작성 필요] (그 시점에 믿고 넘어간 것이 합리적이었는가)
- **대응**: `CLAUDE.md` 3.4절에 "동작한다고 말하기 전에 실제로 실행해서 확인한다. 확인하지 못했으면 그렇다고 말한다"를 명시함
- **증거**: 점검 결과 31/31 통과, 스크린샷 [파일 경로 추가 필요]

### 사례 5. 요청하지 않은 범위 확장 (점검 턴)

### 사례 6. AI의 자기 평가가 틀렸다 — 베이스라인 설명 오류

- **상황**: 재구축 전 `index.html`이 "한 줄짜리 요구사항에서 3~5턴만 진행한 나이브 베이스라인과 다르다"고 AI가 설명했고, "디자인 요청과 기능 추가가 여러 번 있었다"고 썼다.
- **사용자의 반박**: 세부 지시가 아닌 자율성 테스트로 3~5턴을 진행한 것이라 문제가 되는가?
- **재검토 결과**: 내용 변경 턴이 4개로 "3~5턴" 범위 안이고, 요청도 모호한 위임이라 "세부 지시 없이" 조건에 부합했다. AI의 앞선 설명이 사실을 과장했다.
- **관찰**: AI는 자신이 한 작업의 성격을 틀리게 요약할 수 있다. 사용자가 원문 요구사항(README2.md)과 대조해 반박한 것이 오류를 바로잡았다.
