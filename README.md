# Sub-Cut

정기 구독 결제일과 무료 체험 만료일을 한눈에 보여주는 웹 앱입니다.

## 실행

빌드나 설치 없이 `index.html`을 브라우저로 열면 됩니다.

## 기능

- 정기 결제(매월/매년/매주)와 무료 체험 만료일 등록
- 다가오는 순서대로 D-day, 진행 막대, 긴급도 색 표시
- 월간 캘린더에 결제일(●)과 체험 만료일(◆) 표시, 날짜 클릭 시 상세 확인
- 월 예상 지출, 7일 내 일정, 진행 중인 체험 요약
- 구독 수정/삭제
- JSON 내보내기/가져오기로 백업 및 기기 간 이전
- 다크 모드, 모바일 화면 지원

## 데이터

모든 데이터는 브라우저 localStorage에 저장되며 서버로 전송되지 않습니다.
브라우저 데이터를 지우면 사라지므로, 중요한 데이터는 "내보내기"로 백업하세요.
